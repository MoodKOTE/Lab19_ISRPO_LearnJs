## Сравнение JavaScript и C#

| Концепция               | JavaScript                                  | C#                                           |
|------------------------|---------------------------------------------|----------------------------------------------|
| Типизация              | Динамическая, типы определяются во время выполнения | Статическая, строгая типизация               |
| Объявление переменных  | `let`, `const`, `var`                        | явное указание типа (`int`, `string` и т.д.) |
| Функции / методы       | Функции — значения первого класса, стрелочные функции | Методы внутри классов, делегаты              |
| Массивы                | Могут содержать элементы разных типов, динамический размер | Обычно однотипные (`T[]`, `List<T>`)         |
| Объекты                | Создаются без класса, свойства можно добавлять в любой момент | Требуется определение класса или анонимные типы |
| Циклы                  | `for`, `while`, `do...while`, `for...of`, `for...in` | `for`, `foreach`, `while`, `do...while`      |
